# Mouvement et micro-interactions — plan d'implémentation

> **Pour les agents :** exécuter avec `superpowers:executing-plans`, selon les règles du CLAUDE.md global.
> - T1 d'abord.
> - Puis T2 à T5 **en parallèle**, un sous-agent par tâche, chacun dans son worktree (`isolation: "worktree"`), fusionnés par l'orchestrateur.
> - Pas de revue par tâche, pas de commit par tâche : un seul commit à la fin.
> - Chaque sous-agent rend un rapport de 10 lignes maximum.

**But :** rendre chaque interaction de Little Steps fluide et naturelle. Les moyens :
- des ressorts qui gardent leur vitesse et changent de cible en cours de route ;
- un appui « bouton 3D » ;
- des vibrations et des sons ;
- maintenir pour compléter ;
- une chorégraphie de validation ;
- plus aucun saut de mise en page.

**Architecture :**
- **T1 (socle)** apporte les primitives :
  - jetons de ressort ;
  - `SpringBuilder` et `Pop` ;
  - `PressScale` / `PressSink` ;
  - `FadeThroughSwitcher` ;
  - `RollingText` directionnel ;
  - le service `FeedbackService` (haptique + sons + réglages) ;
  - la mémoire des célébrations ;
  - les textes l10n ;
  - le harnais de test.
- **T2 à T5** appliquent ces primitives, chacune dans une zone de fichiers disjointe :
  - T2 : widgets partagés, coquille et célébrations globales ;
  - T3 : accueil ;
  - T4 : création et fiches ;
  - T5 : progrès, trophées, profil.

**Stack :** Flutter 3.47 / Dart 3.13, Riverpod 3, go_router 18, Drift, `audioplayers` (nouvelle dépendance, §T1).

**Spec :** `docs/superpowers/specs/2026-10-25-motion-design.md`. Chaque tâche lit la spec en entier ; les § ci-dessous y renvoient.

## Contraintes globales

- **Jetons de ressort** : `press` 300 ms / rebond 0,30 · `snappy` 250 / 0,15 · `smooth` 350 / 0 · `fill` 500 / 0 · `pop` 350 / 0,45.
- **Effets** : couleurs et opacités en interpolation `Motion.fast` (150 ms) ou `Motion.medium` (220 ms), courbe `Motion.curve`. **Plus aucune durée codée en dur ni courbe linéaire dans `lib/`.**
- **Reduce motion** : tout passe par `context.motion(...)` ou par `SpringBuilder`, qui saute à la cible. Pas de confettis, ni de `Pop`, ni de vol d'XP quand `MediaQuery.disableAnimations` est vrai.
- **Aucune onde (splash) Material** : `NoSplash` dans le thème.
- **Pas de nouvelle dépendance** hors `audioplayers`.
- **Accessibilité** : cibles de 48 px, Semantics et grand texte inchangés ou améliorés.
- **Textes** : uniquement via les ARB EN/FR créés en T1, en tutoyant.
- **Tests** : la suite existante (270) reste verte ; `flutter analyze` sans aucun problème.

## Points de revue

Cinq cas que la spec implique sans les nommer. Chacun a un test dans la tâche qui en est propriétaire :

1. **Scroll pendant un maintien** : un doigt posé sur une pilule qui part en scroll ne doit jamais compléter (T3).
2. **Lancement de l'app** : ouvrir l'app avec un historique déjà parfait, de niveau 3 avec des badges, ne déclenche aucune célébration, ni haptique ni son (T2).
3. **Échec du lecteur audio ou du canal haptique** : il n'empêche jamais l'action et ne lève rien jusqu'à l'UI (T1).
4. **Rafales sur deux habitudes** : une rafale sur A puis un tap sur B ; « Annuler » restaure B à sa valeur d'avant **sa** rafale, A garde sa valeur (T3).
5. **Maintien avec « réduire les animations »** : le maintien complète quand même au seuil, sans charge visuelle (T3).

abstract final class Springs {
  static final SpringDescription press, snappy, smooth, fill, pop; // valeurs des contraintes globales
}
/// Courbe tirée d'un ressort sans rebond (pour AnimatedSize & co.).
class SpringCurve extends Curve { const SpringCurve(this.spring, this.duration); }

// spring_builder.dart
class SpringBuilder extends StatefulWidget {
  const SpringBuilder({super.key, required double value, required SpringDescription spring,
    required Widget Function(BuildContext context, double value, Widget? child) builder,
    Widget? child, double? from});
  // `from` : valeur au montage (défaut = value). Change de cible en gardant la vitesse.
  // Contrôleur non borné. Reduce motion : saute à la cible.
}
class Pop extends StatefulWidget {
  const Pop({super.key, required int trigger, required Widget child, double peak = 1.04, bool anticipate = true});
  // Joue quand `trigger` augmente. Anticipation 0,97 pendant ~80 ms, puis pic `peak` et retour à 1 avec Springs.pop.
}

// press_scale.dart
class PressScale  // même API qu'avant ; appui ~70 ms vers `scale`, remontée Springs.press depuis l'état courant
class PressSink extends StatefulWidget {
  const PressSink({super.key, required double depth, bool enabled = true,
    required Widget Function(BuildContext context, double pressed) builder});
  // pressed ∈ ~[−0.3, 1] (le rebond passe sous 0) : l'appelant translate de depth*pressed et réduit son ombre d'autant.
  // Tap très bref : l'enfoncement atteint au moins 0,6 avant de remonter. Glisser au-delà de kTouchSlop annule.
}

// fade_through_switcher.dart
class FadeThroughSwitcher extends StatelessWidget {
  const FadeThroughSwitcher({super.key, required Widget child, AxisDirection? direction,
    AlignmentGeometry alignment = AlignmentDirectional.topStart});

}
